# Password Strength Checker

A CLI tool that checks a password against 5 rules and rates it as Weak, Medium, or Strong.

## Rules checked
- At least 8 characters
- Contains an uppercase letter
- Contains a lowercase letter
- Contains a digit
- Contains a special character (!@#$%^&*')

## What I learned
- Looping through a string character by character
- Using flag variables to track pass/fail across a loop
- Building a simple scoring system with if/elif/else
